1. Google Cloud Console

Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client IDs → Web application

1-1. Authorized redirect URIs
https://empecs.lunarsystem.co.kr/api/auth/google/callback
1-2. Authorized JavaScript origins
https://empecs.lunarsystem.co.kr

생성 후 Client ID, Client Secret을 서버 담당자에게 전달하세요.

2. Kakao Developers

내 애플리케이션 → 해당 앱 → 플랫폼 → Web → Redirect URI

2-1. Redirect URI
https://empecs.lunarsystem.co.kr/api/auth/kakao/callback

동의항목에서 이메일·프로필 활성화 후, REST API 키를 서버 담당자에게 전달하세요.

3. Apple Developer (Sign in with Apple)

Apple Developer → Certificates, Identifiers & Profiles → Identifiers → Services ID

3-1. Services ID (Identifier)
com.empecs.cg21.web
3-2. Redirect URL (Sign in with Apple 설정 시)
https://empecs.lunarsystem.co.kr/auth/callback

FE 로그인 완료 후 토큰 수신 페이지와 동일합니다. Google/Kakao OAuth 후 BE가 리다이렉트하는 경로(#token=)와 맞춥니다.

Key ID, Team ID, .p8 Private Key가 필요하면 서버 담당자와 협의하세요.
